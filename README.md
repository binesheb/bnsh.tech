# bnsh.tech

The public operating layer of **BNSH** — a technology, design, automation and experimental systems studio.

## What lives here

- **Projects** — products and systems built under BNSH.
- **Lab** — experiments, prototypes and works in progress.
- **Journal** — notes, ideas and technical explorations.
- **GitHub-connected activity** — the wider open-source ecosystem remains the source of truth.

## Stack

- Next.js
- TypeScript
- Tailwind CSS
- Static-first architecture with server-side GitHub integration where useful

## Development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Principles

1. Build useful things.
2. Keep systems understandable.
3. Prefer clean interfaces and durable architecture.
4. Treat experiments as first-class work.
5. Keep the website lightweight and fast.

## Repository structure

```text
app/            Application routes and pages
components/     Reusable interface components
lib/            Data and integrations
public/         Static assets
```
